# Snake-Water-Gun Game 🐍💧🔫

A simple command-line Snake-Water-Gun game built using Python.

## Features
- Play against the computer
- Random computer choices
- Win, lose, and draw logic
- Input validation
- Score tracking
- Play multiple rounds until you quit

## Technologies Used
- Python
- `random` module

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open the project folder in a terminal.
4. Run:

   `python main.py`

## Learning Outcomes
This project helped me practise Python functions, conditional statements, loops, user input, and basic game logic.

Built as a Python learning project.
